# ملاحظات إعادة التصميم — Blue Mobile v4

## ما الذي تغيّر

### 1) واجهة جديدة موحّدة (فاتحة احترافية)
- تبديل الهيكل من شريط علوي إلى **شريط جانبي RTL** (شعار + 8 أقسام) + **شريط علوي** (مستخدم + تاريخ/وقت + حالة الاتصال).
- لوحة ألوان فاتحة هادئة: أبيض / أزرق `#1d4ed8` / رمادي فاتح، بطاقات بحواف ناعمة وظلال خفيفة، جداول وحقول وأزرار موحّدة عبر كل الشاشات.
- **الرئيسية**: بانر ترحيب + 8 اختصارات سريعة تنقل للمقاطع مباشرة.
- **التقارير**: أزرار نطاق سريعة (آخر 7 أيام / آخر 30 يوم / كل الوقت) تعبّئ الفلاتر وتشغّل البحث.
- **بوابة الدخول** بخلفية فاتحة وبطاقة نظيفة.
- الوضع الداكن ما زال متاحًا من الإعدادات — الآن **الفاتح هو الافتراضي**.
- تجاوب كامل: على الشاشات الضيقة يتحول الشريط الجانبي إلى شريط تنقل سفلي، بلا تمرير أفقي.

### 2) كل الوظائف كما هي
لا تغيير على أي منطق عمل أو مسارات API أو قاعدة بيانات. كل المعرفات والفئات التي يعتمد عليها `Blue-Mobile.js` محفوظة. التعديلات الوظيفية كلها إضافات ربط (اختصارات + نطاقات تقارير + مزامنة اسم المستخدم بالشريط العلوي).

### 3) أخطاء قديمة أُصلحت (كانت موجودة قبل إعادة التصميم)
| الخطأ | الإصلاح |
|---|---|
| كتلة CSS يتيمة خارج `<style>` (سطر ~1490) كانت تُحقن كنص داخل الصفحة وتزيح التخطيط 150px | تغليفها بوسم `<style>` صحيح |
| شارات حالة المخزون `.stock-ok/low/out` تُولَّد بدون صنف `.stock-chip` فتظهر الأيقونة بحجم عملاق | قواعد حجم موحّدة في ورقة التصميم |
| `/api/reports/dashboard` يعيد `today.expenses/purchases` ككائن `{total,…}` بينما الواجهة تستخدمهما كرقم → ظهور NaN في بطاقات اليوم | توحيد الشكل عند استلام الرد في `App.state` |
| ترتيب طبقات العرض: الشريط الجانبي كان يحيط الأدراج/النوافذ (z-index) | ضبط الطبقات: sidebar 60 < drawer 90 < ctx 95 < modal 100 < gate 400 |
| تجاوز أفقي على الهاتف (بطاقات الجداول العريضة داخل شبكات flex/grid) | `min-width:0` على عناصر الشبكات + تمرير أفقي داخل `.table-wrap` |
| سباقات اختبار e2e: انتظار ظهور التوست دون التحقق من نصه (توست واحد مشترك) | انتظار نص الرسالة الصحيح في `tests/e2e.test.js` |
| تعارض ترقيم/تطبيق التهجرات: `INSERT INTO schema_migrations` مكرر داخل 005/006 يفشل على التنصيب النظيف | حذف الإدخال الذاتي من ملفي التهجئة |

### 4) نتائج الاختبار قبل التسليم
- `npm test` (واجهة برمجية): **111/111 ✓** على تنصيب نظيف (كل التهجرات السبعة تُطبَّق بنجاح).
- `npm run test:e2e` (متصفح حقيقي): **57/57 ✓** — بيع نقدي/بطاقة/IMEI، مشتريات، مصروفات، صندوق، مرتجعات، جرد، إغلاق يومية، تقارير، إعدادات، صفر أخطاء JavaScript.
- تدقيق بصري بـ Playwright: كل الشاشات (8 أقسام × فاتح/داكن × سطح مكتب/هاتف) + صفر أخطاء كونسول وطلبات فاشلة.

### 5) التشغيل
```bash
npm install
cp .env.example .env   # أو أنشئ .env (DATABASE_URL, SESSION_SECRET, PORT)
npm run migrate
npm start              # http://localhost:3000
# بيانات تجريبية اختيارية (والسيرفر يعمل):
npm run seed
```
